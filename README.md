# 해 뜰 때까지 (마지막 등대 2)

「마지막 등대」의 후속작입니다. 1편이 끝나고 한 해 뒤, 해안 마을에 다시 안개가 낍니다.
해가 지면 홀린 이웃들이 그림자가 되어 마을로 옵니다. 죽이지 않고 안개를 걷어 깨우며, 해가 뜰 때까지 문을 지킵니다.

설치 없이 `index.html` 하나로 휴대폰 브라우저에서 실행되는 세로형 디펜스 게임입니다.
진행 기록은 브라우저 localStorage에 저장됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages(Settings → Pages → Branch: `main` / root)로 배포하면 바로 플레이할 수 있습니다.

## 지금 들어 있는 것 (시험판: 첫 장소 「등대」의 세 밤)
- 밤마다 조건 카드 셋 중 하나를 고르고, 낮에 문 자리와 채비(해자, 구덩이, 망루, 등유통)를 정한 뒤 열두 물결을 넘깁니다.
- 우리 편 여섯: 작살꾼, 도리깨꾼, 사냥꾼, 등불지기(빛 사슬), 엿장수(엿가락), 화염병. 대장간에서 여덟 단까지 벼리고 4단에서 갈래를 고릅니다.
- 그림자 일곱 종과 금빛 보물 그림자. 보물 그림자의 설계도 조각을 모아 새벽에 맞추면 장치(돌 대포, 가짜 등불, 마을 종, 거울)를 얻습니다.
- 들판 전체를 쓸고 가는 등대 빛, 연쇄 깨우기, 여섯째 물결 뒤 한밤의 선택.
- 찢어진 설계도 조각을 끌어다 맞추는 퍼즐(25초 안에 맞추면 장치가 한층 세다).
- 밤에는 조작 띠가 얇아져 들판이 크게 보인다. 장부의 단서 탭에서 1편 느낌 유닛 그림 시안으로 바꿔 볼 수 있다.
- 유품으로 불러내는 영혼 장수 넷, 새벽 꾸러미(빈 꾸러미 없음).
- 색유리풍 이야기 삽화.
